Документація SPARQL-запиту до WikiData

🧠 Загальний опис

Цей SPARQL-запит отримує інформацію про осіб, які пов’язані з Україною (як сучасною державою, так і її історичними формуваннями), та мають сторінку у українській Вікіпедії.

Результатом роботи запиту є дані про місце народження, їх координати, дату народження, якщо відомо: місце смерті, їх координати, стать та інше.

Сервіс запитів Вікіданих (Wikidata Query Service): https://query.wikidata.org

Це спеціальний інструмент, який дозволяє отримувати структуровані дані з Вікіданих за допомогою запитів.

Вікідані (Wikidata): Це велика безкоштовна, спільна, багатомовна база знань, яка збирає структуровані дані для підтримки Вікіпедії та інших проєктів Фонду Вікімедіа, а також для використання будь-ким у світі. У Вікіданих зберігаються факти про мільйони речей (людей, місця, концепції тощо) та їхні взаємозв'язки.

🔍 Приклад запиту:

SELECT ?person ?personLabel ?birthPlaceLabel ?birthDate ?coordinates ?deathPlaceLabel 
       ?coordinates_death ?deathDate ?wikipedia ?sexLabel ?ukraineRelatedEntityLabel
WHERE {
  ?person wdt:P31 wd:Q5.                          # Людина
  VALUES ?ukraineRelatedEntity {
    wd:Q212 wd:Q133356 wd:Q243610
    wd:Q457167 wd:Q950644 wd:Q212439
    wd:Q239502 wd:Q1108445
  }

  {
    ?person wdt:P27 ?ukraineRelatedEntity.       # Громадянство
  }
  UNION {
    ?person wdt:P19 ?placeOfBirth.               # Місце народження
    ?placeOfBirth wdt:P17 ?ukraineRelatedEntity.
  }

  ?wikipedia schema:about ?person;
            schema:isPartOf <https://uk.wikipedia.org/>.

  ?person wdt:P19 ?birthPlace.
  ?birthPlace wdt:P625 ?coordinates.

  OPTIONAL { ?person wdt:P20 ?deathPlace. 
             ?deathPlace wdt:P625 ?coordinates_death. }
  OPTIONAL { ?person wdt:P570 ?deathDate. }

  ?person wdt:P569 ?birthDate.
  OPTIONAL { ?person wdt:P21 ?sex. }

  SERVICE wikibase:label { bd:serviceParam wikibase:language "uk". }
  LIMIT 100
}

👥 Як обираються особи

  • Тип: особа (wdt:P31 wd:Q5 – "instance of human"). Тобто, вибираються статті лише про людей.
  • Походження: Визначає зв'язок з Україною через громадянство або місце народження. Тобто люди або мали громадянство історичної чи сучасної України (wdt:P27), або народилися на території однієї з визначених держав (список вказаний нище) (wdt:P19 → wdt:P17).
  • Обов’язкові умови:
    • Повинна існувати сторінка про особу в українській Вікіпедії.
    • На сторінці повинно бути вказано місце народження, оскільки для відображення на карті потрібні координати місця народження.
    • Має бути вказана дата народження.
  • Додаткові умови: місце смерті, дата смерті, стать.

❓ FAQ

Чому стаття про певну людину не потрапила в аналіз?

  • Її немає в українській Вікіпедії.
  • Не виконується одна з умов:
    • Не вказано або некоректно вказано місце народження, яке має відповідати коду: wdt:P17 (місце народження).
    • Особа не має приналежності до України чи її історичних формувань (наведені у списку вище), або ця приналежність некоректно вказана в статті. Має правильно відповідати коду wdt:P27 (громадянство, національність).
  • Також можуть бути збої і помилки у роботі Wikidata Query Service, однією з причин може бути погано або неправильно сформована стаття.
