Документація SPARQL-запиту до WikiData

🧠 Загальний опис

Цей SPARQL-запит отримує інформацію про осіб, які пов’язані з Україною (як сучасною державою, так і її історичними формуваннями), та мають сторінку у українській Вікіпедії. Запит повертає дані про місце народження, дату народження, місце смерті (якщо відомо), дату смерті, стать, координати народження та смерті (якщо відомо).

🔍 Приклад запиту:

SELECT ?person ?personLabel ?birthPlaceLabel ?birthDate ?coordinates ?deathPlaceLabel 
       ?coordinates_death ?deathDate ?wikipedia ?sexLabel ?ukraineRelatedEntityLabel
WHERE {
  ?person wdt:P31 wd:Q5.                          # Людина
  VALUES ?ukraineRelatedEntity {
    wd:Q212 wd:Q133356 wd:Q243610
    wd:Q457167 wd:Q950644 wd:Q212439
    wd:Q239502 wd:Q1108445
  }

  {
    ?person wdt:P27 ?ukraineRelatedEntity.       # Громадянство
  }
  UNION {
    ?person wdt:P19 ?placeOfBirth.               # Місце народження
    ?placeOfBirth wdt:P17 ?ukraineRelatedEntity.
  }

  ?wikipedia schema:about ?person;
            schema:isPartOf <https://uk.wikipedia.org/>.

  ?person wdt:P19 ?birthPlace.
  ?birthPlace wdt:P625 ?coordinates.

  OPTIONAL { ?person wdt:P20 ?deathPlace. 
             ?deathPlace wdt:P625 ?coordinates_death. }
  OPTIONAL { ?person wdt:P570 ?deathDate. }

  ?person wdt:P569 ?birthDate.
  OPTIONAL { ?person wdt:P21 ?sex. }

  SERVICE wikibase:label { bd:serviceParam wikibase:language "uk". }
  LIMIT 100
}

👥 Як обираються особи

  • Тип: особа (wdt:P31 wd:Q5 – "instance of human").
  • Походження: Визначає зв'язок з Україною через громадянство або місце народження. Тобто люди або мали громадянство історичної чи сучасної України (wdt:P27), або народилися на території однієї з визначених держав (wdt:P19 → wdt:P17).
  • Обов’язкова умова: повинна існувати сторінка про особу в українській Вікіпедії.

  • Київська Русь (Q1108445)

📦 Які дані повертає запит

  • ?person – ID особи у WikiData
  • ?personLabel – Ім’я особи (українською)
  • ?birthPlaceLabel – Назва місця народження
  • ?birthDate – Дата народження
  • ?coordinates – Геокоординати місця народження
  • ?deathPlaceLabel – Місце смерті (якщо є)
  • ?coordinates_death – Координати місця смерті (якщо є)
  • ?deathDate – Дата смерті (якщо є)
  • ?wikipedia – Посилання на сторінку в українській Вікіпедії
  • ?sexLabel – Стать
  • ?ukraineRelatedEntityLabel – Назва пов’язаної української держави
